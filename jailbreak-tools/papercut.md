# PaperCut

> [!NOTE]
> This serves to act as a less active mirror of [PaperCut's Forgejo](https://git.huckle.dev/TheHuckle/papercut).

PaperCut, created by [**Huckle**](https://huckle.dev/), is a lightweight, cross-platform desktop installer for Kindle jailbreaks, hotfixes, and other mods.

Built with NeutralinoJS, PaperCut avoids large resource intensive builds and is inspired by the GNOME Human Interface Guidelines.

## Features

- **Automatic Kindle detection**
- Install options:
  - Jailbreaks (WinterBreak, WinterBreak2, AdBreak)
  - Hotfix (HAKT)
  - Disable ADs
  - PEKI
  - KindleForge
  - KOReader
  - KTerm
  - KoSSH
  - screenControl
- Step by step instructions
- Lightweight for quick download
- Cross-platform (macOS, Windows, Linux)
